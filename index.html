⚡ HOW IT WORKS
1

PR Opened

Poly-Glot receives a webhook when a pull request is opened or updated.

2

AI Analysis

Each changed file is analyzed by OpenAI or Anthropic. Functions, classes, and logic are parsed.

3

Comments Posted

Inline review comments are added with doc comments, intent explanations, and edge-case warnings.

💬 COMMENT MODES

Both — Documentation + Intent

/**
 * Validates and refreshes an expired user session token.
 *
 * @param {string} token - The JWT session token to validate.
 * @param {Object} opts - Refresh options including grace period.
 * @returns {Promise<Session>} Refreshed session or throws AuthError.
 * @throws {AuthError} If token is revoked or user is deactivated.
 *
 * 💡 WHY: Sessions expire after 30min of inactivity. This function
 * handles the "sliding window" pattern — extending active sessions
 * while forcing re-auth for truly idle users. The grace period
 * prevents race conditions during concurrent API calls.
 */

⚙️ CONFIGURATION

Add .polyglot.yml to your repository root:

# AI provider
provider: openai
 
# Comment mode
mode: both
 
# Coverage threshold (0.0–1.0)
coverage_threshold: 0.5
 
# Max files per PR
max_files: 15
 
# Review style
review_style: inline

💡 Click values to cycle through options
