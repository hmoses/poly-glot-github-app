poly-glot-ai 📄 DOC
refresh_session(token, grace_period=30) → Session

Validates a JWT session token and refreshes it if still within the activity window.

@param token — JWT session token string
@param grace_period — Extra seconds beyond 30min timeout (default: 30)
@returns Session — with new token and user data
@raises AuthError — if session is revoked or fully expired
🦜
poly-glot-ai 💡 WHY
The grace period prevents unnecessary token regeneration when a session is still active. Without it, every request near expiry would trigger a Redis write and new JWT encode — adding latency and Redis load during peak traffic.
